# LitWorks 📖✨

**Интеллектуальная платформа для чтения с персонализированными рекомендациями и системой прогресса**

![Литературный логотип или скриншот интерфейса] <!-- Можно добавить позже -->

## 🔍 О проекте
Платформа объединяет:
- 📚 **Поддержку форматов**: EPUB, PDF (с конвертацией)
- 🧠 **AI-рекомендации** на основе предпочтений (жанры, авторы, история чтения)
- 📊 **Систему прогресса** с XP и уровнями (Новичок → Эксперт)
- 👥 **Сообщество** книжных клубов и мероприятий

**Цель**: Увеличить вовлечённость читателей на 40% (Pew Research, 2023).

---

## 🛠 Готовый функционал (Iteration 1-3)
✅ **Ядро системы**:
- Регистрация + тест предпочтений
- Читалка с настройкой шрифтов/фона
- Базовая модель данных (`Книга`, `Пользователь`, `Библиотека`)

✅ **Автоматизации**:
- Конвертер EPUB/PDF
- Синхронизация библиотеки между устройствами
- Логирование действий пользователей

---

## 🚧 В разработке (Iteration 4)
🛠 **Система прогресса**:
- Начисление XP за чтение/заметки/обсуждения
- Уровни: `Новичок` (0-100XP), `Опытный` (100-500XP)

🛠 **Интеграции**:
- Платежи (Premium подписка $5/мес)
- Cloudflare для безопасности
- API издательств (20+ партнёрств)
